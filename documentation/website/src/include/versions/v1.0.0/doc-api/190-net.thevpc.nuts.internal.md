# Package net.thevpc.nuts.internal

<a id="pkg-net-thevpc-nuts-internal"></a>

Internal Nuts implementation support; not a public extension or application API.



Types in this package support API defaults, adapters, and compatibility helpers.
They may change without notice. Runtime wiring contracts are isolated further in
[net.thevpc.nuts.internal.rpi](#cls-net-thevpc-nuts-internal-rpi); consumers must not invoke or implement them
directly.
