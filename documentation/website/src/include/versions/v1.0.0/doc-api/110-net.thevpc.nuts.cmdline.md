# Package net.thevpc.nuts.cmdline

<a id="pkg-net-thevpc-nuts-cmdline"></a>

Provides utilities and abstractions for command-line parsing, processing, and completion.



Features included in this package:


- **Command-line parsing:** Define commands, arguments, and options, and parse input into structured objects.
- **Argument handling:** Support for argument types, validation, default values, and candidate suggestions.
- **Auto-completion:** Tools to implement interactive shell-style completion of commands and arguments.
- **Execution:** Helpers to process parsed commands, run tasks, and maintain command-line state and history.





This package aims to provide a flexible, extensible framework for CLI applications,
supporting both simple scripts and complex interactive command-line tools.

<a id="cls-net-thevpc-nuts-cmdline-NArg"></a>

## NArg

```java
public interface NArg extends NBlankable
```

Represents a parsed command-line argument with a dual-source value model.



An argument has two distinct value sources, reflected in three method families:





- **`asXxx()`** — interprets the __full image__ (raw string) as a typed value.
      Works on non-option args like `"3"` or `"true"`.
      Example: `NArg.of("3").asInt()` → `NOptional.of(3)`
      Example: `NArg.of("--count=3").asInt()` → `NOptional.ofError()`
- **`getXxxValue()`** — interprets the __value segment__ (after `=`),
      with option-aware semantics (negation, flag presence).
      Example: `NArg.of("--count=3").getIntValue()` → `NOptional.of(3)`
      Example: `NArg.of("--distinct").getBooleanValue()` → `NOptional.of(true)`
      Example: `NArg.of("--!distinct").getBooleanValue()` → `NOptional.of(false)`
- **`xxxValue()`** — same as `getXxxValue()` but throws instead of
      returning `NOptional`.





The two literal anchors are:




- [#asLiteral()](#m-asLiteral) — the full raw image, feeds `asXxx()`
- [#literalValue()](#m-literalValue) — the value segment only, feeds `getXxxValue()`





Note: the value segment may be implicit (no `=` present) depending on how
the argument was produced by [NCmdLine](#cls-NCmdLine):


- `nextEntry("--a")` → value segment is `null`
- `nextFlag("--a")` → value segment is implicitly `true`






**Author:** thevpc

**Since:** 0.5.5

## NCmdLine

```java
public interface NCmdLine extends Iterable<NArg>, NBlankable
```

Simple Command line parser implementation. The command line supports
arguments in the following forms :


- non option arguments : any argument that does not start with '-'
- long option arguments : any argument that starts with a single '--' in the
form of
```java
--[//][!]?[^=]*[=.*]
```


- // means disabling the option
- ! means switching (to 'false') the option's value
- the string before the '=' is the option's key
- the string after the '=' is the option's value


Examples :


- --!enable : option 'enable' with 'false' value
- --enable=yes : option 'enable' with 'yes' value
- --!enable=yes : invalid option (no error will be thrown but the result is
undefined)
- simple option arguments : any argument that starts with a single '-' in the
form of
```java
-[//][!]?[a-z][=.*]
``` This is actually very similar to long options


- -!enable (with expandSimpleOptions=false) : option 'enable' with 'false'
value
- --enable=yes : option 'enable' with 'yes' value
- --!enable=yes : invalid option (no error will be thrown but the result is
undefined)
- condensed simple option arguments : any argument that starts with a single
'-' in the form of
```java
-[//]([!]?[a-z])+[=.*]
``` This is actually very similar to long
options and is parsable when expandSimpleOptions=true. When activating
expandSimpleOptions, multi characters key will be expanded as multiple
separate simple options Examples :


- -!enable (with expandSimpleOptions=false) : option 'enable' with 'false'
value
- --enable=yes : option 'enable' with 'yes' value
- --!enable=yes : invalid option (no error will be thrown but the result is
undefined)
- long option arguments : any argument that starts with a '--'


option may start with '!' to switch armed flags expandSimpleOptions : when
activated

**Since:** 0.5.5
