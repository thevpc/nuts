# Package net.thevpc.nuts.time

<a id="pkg-net-thevpc-nuts-time"></a>

Provides utilities for time measurement, duration formatting, and progress tracking.



This package includes:


- **memory and chronometers** for measuring elapsed time, timestamps, and scheduling.
- **Progress tracking** to represent the advancement of tasks or operations, including
        hierarchical or aggregated progress.





**Design rationale for progress:**


- Progress is independent of concurrency. It represents the logical completion state of a task,
        whether executed in a single thread or multiple threads.
- Progress can be subdivided into sub-progresses, aggregated, and reported through events.
- Progress can integrate with concurrent execution, but it is fundamentally about monitoring
        task advancement and duration estimation, not about managing threads.

## NDuration

```java
public class NDuration implements Serializable, NElementSimple
```

NDuration represents a comprehensive and precise time duration
with support for multiple temporal units ranging from nanoseconds
up to years. Unlike `java.time.Duration`, which is limited
to seconds and nanoseconds, NDuration allows tracking weeks, months,
and years, providing full temporal granularity for long-term
scheduling, reporting, and time calculations.



**Key Features:**


- Supports all standard temporal units: nanoseconds, microseconds,
      milliseconds, seconds, minutes, hours, days, weeks, months, and years.
- Immutable once constructed.
- Normalization support to ensure unit values are consistent with
      conventional temporal rules (e.g., 1000 milliseconds → 1 second).
- Support for arithmetic operations: addition, subtraction, multiplication,
      negation.
- Conversion methods to [Duration](#cls-Duration), milliseconds, seconds, or
      nanoseconds.
- Support for defining smallest and largest considered units for calculations.





**Usage Examples:**
```java
// Create a duration of 2 hours, 30 minutes, and 45 seconds
NDuration duration = new NDuration(0, 0, 0, 0, 2, 30, 45, 0, 0, 0, ChronoUnit.NANOS, ChronoUnit.HOURS);

// Convert to java.time.Duration
Duration javaDuration = duration.toDuration();

// Add another duration
NDuration combined = duration.add(NDuration.ofUnit(15, ChronoUnit.MINUTES));

// Normalize duration so that all unit values are consistent
NDuration normalized = combined.normalize();

// Multiply duration by 2
NDuration doubled = normalized.mul(2);
```



Internally, NDuration stores milliseconds and nanoseconds for precision,
while keeping separate fields for each larger temporal unit. It can
operate with partial durations (e.g., only hours and minutes) or full
durations covering all units.
