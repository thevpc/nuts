# Package net.thevpc.nuts.pipeline

<a id="pkg-net-thevpc-nuts-pipeline"></a>

Lazy iteration and stream-like pipeline abstractions.



`NIterable`, `NIterator`, and `NStream` provide Nuts-native
traversal contracts, with builders, delegates, optional iteration, and configurable
iterator error handling.
