# Package net.thevpc.nuts.reflect

<a id="pkg-net-thevpc-nuts-reflect"></a>

Reflection, type descriptions, member/property access, and object mapping.



The package exposes reflected types, methods, parameters, properties, signatures,
type names, repositories, converters, and configurable mapping strategies. Bean
containers and references provide implementation-neutral bean lookup and identity.

<a id="m-NReflectUtils-getDefaultValue"></a>

#### getDefaultValue

```java
@SuppressWarnings("unchecked")
public static <T> T getDefaultValue(Class<T> type)
```

Resolves the default value for a type annotated with `@DefaultsTo`.



This method checks for default values in the following order:


- **Primitive defaults** — Java primitive types return their language defaults
      (e.g., 0 for int, false for boolean, 0.0 for double)
- **Cache** — previously resolved defaults to avoid repeated reflection
- **@DefaultsTo annotation** — if present on the type, resolves the specified member





**Resolution strategy for @DefaultsTo:**



For enum types, treats the annotation value as an enum constant name.
For other types, attempts to resolve in order:


- Public static field with the given name
- Public static no-arg method with the given name





**Caching:** Results (including `null`) are cached to avoid repeated reflection.
This includes cases where no annotation is present. Cached nulls represent "no annotation found",
not resolution failures.



**Error handling:**


- If `@DefaultsTo` annotation is present but the specified member cannot be found
      or has the wrong signature, a [NoSuchElementException](#cls-NoSuchElementException) is thrown.
- If member invocation/field access throws an exception, it is wrapped in a
      [NoSuchElementException](#cls-NoSuchElementException) with context.





**Examples:**
```java
@DefaultsTo("UNKNOWN")
  enum Status { ACTIVE, INACTIVE, UNKNOWN }
  Status s = getDefaultValue(Status.class);  // returns Status.UNKNOWN

  @DefaultsTo("DEFAULT_INSTANCE")
  class Config {
      public static final Config DEFAULT_INSTANCE = new Config();
  }
  Config c = getDefaultValue(Config.class);  // returns Config.DEFAULT_INSTANCE

  @DefaultsTo("create")
  class Factory {
      public static Factory create() { return new Factory(); }
  }
  Factory f = getDefaultValue(Factory.class);  // returns result of Factory.create()
```

**Parameters:**

- `type` - the class to check for a default value; may be null

**Returns:**

the resolved default value, or a Java primitive default if no annotation present,
or `null` if type is null or no `@DefaultsTo` annotation is found

**Throws:**

- `NoSuchElementException` - if `@DefaultsTo` annotation is present but:
                               <ul>
                                 <li>For enum: the specified constant name does not exist</li>
                                 <li>For class: the specified field or method is not found</li>
                                 <li>For method: it has parameters (only no-arg methods are supported)</li>
                                 <li>For field/method: invocation or access throws an exception</li>
                               </ul>

**See Also:** NDefaultsTo, #getJavaDefaultValue(Type)

#### isValidIdentifier

```java
public static boolean isValidIdentifier(String anyType, String extraWordChars)
```

Validates whether a string is a valid identifier for use in code or configuration.



An identifier is considered valid if:


- Non-null and non-empty
- First character is a valid Java identifier start character (letter, underscore, or dollar sign),
      or present in `extraWordChars` if provided
- Subsequent characters are valid Java identifier parts (letters, digits, underscores, or dollar signs),
      or present in `extraWordChars`
- Does not start or end with underscore, hyphen, or dot





**Extra characters:** The `extraWordChars` parameter allows additional characters
to be considered valid at any position (e.g., hyphens for kebab-case identifiers in configuration files).
If `extraWordChars` is null or doesn't contain a character, that character is rejected unless
it's a valid Java identifier character.



**Examples:**
```java
isValidIdentifier("myVariable", null)           // true
  isValidIdentifier("_myVariable", null)          // false (starts with underscore)
  isValidIdentifier("my-variable", "-")           // true (hyphen in extraWordChars)
  isValidIdentifier("my.property.", ".")          // false (ends with dot)
  isValidIdentifier("2ndVariable", null)          // false (starts with digit)
```

**Parameters:**

- `anyType` - the string to validate as an identifier; may be null
- `extraWordChars` - additional characters to permit in the identifier, or null
                      for strict Java identifier rules only

**Returns:**

`true` if the string is a valid identifier, `false` otherwise

#### findAllSuperClassesAndInterfaces

```java

```

Finds all superclasses and interfaces in the type hierarchy of a given class.



This method performs a breadth-first traversal of the class hierarchy, collecting:


- The input class itself
- All superclasses (excluding `Object.class`)
- All interfaces directly and indirectly implemented





**Traversal order:** Results are returned in breadth-first order, meaning
direct superclasses and interfaces appear before transitive ones. The exact order within
each level is determined by insertion order (LinkedHashSet).



**Special case:** `Object.class` is excluded from the result.
If the input is `null`, it is silently skipped.



**Example:**
```java
class C extends B implements I1, I2 { }
  class B implements I3 { }

  findAllSuperClassesAndInterfaces(C.class)
  // Returns: [C, B, I1, I2, I3]
```

**Parameters:**

- `clazz` - the class to analyze; may be null

**Returns:**

a set of all superclasses and interfaces in the hierarchy,
excluding `Object.class`; empty set if input is null

**See Also:** #findClassHierarchy(Class, Class)

<a id="m-NReflectUtils-loadServices"></a>

#### loadServices

```java
public static <T> void loadServices(Class<T> type, Consumer<T> consumer, Class<?> sources)
```

Discovers and loads service implementations using Java's [ServiceLoader](#cls-ServiceLoader).



This method searches for service implementations via META-INF/services files
using multiple class loaders for maximum coverage:


- Class loaders from `sources` parameters
- The service type's own class loader
- The current thread's context class loader
- The class loader of `NReflectUtils` (this library)





**Duplicate prevention:** If the same implementation class is discovered
multiple times (e.g., via different class loaders), the consumer is called only once per unique class name.



**Error handling:** If loading fails for any class loader, a warning is logged
and the search continues with other loaders. No exception is thrown.



**Example:**
```java
loadServices(DataSourceFactory.class, factory -> {
      System.out.println("Found: " + factory.getClass().getName());
  }, DatabaseDriver.class);
```

**Parameters:**

- `type` - the service interface or class to load implementations for; may not be null
- `consumer` - callback invoked for each discovered service instance; may not be null

<a id="m-NReflectUtils-unproxyType"></a>

#### unproxyType

```java
public static Class<?> unproxyType(Class<?> aClass)
```

Unwraps a proxy class to recover the underlying real type.



For proxy instances created by common frameworks (Hibernate, Spring CGLIB, JDK proxies),
this method recursively traverses the class hierarchy to find the original non-proxy type.



**Behavior by proxy kind:**


- **JDK Dynamic Proxies:** Returns the first interface implemented by the proxy.
      This is a heuristic; if the proxy implements multiple interfaces, one is arbitrarily chosen.
      The actual target object type cannot be recovered from the proxy class alone.
- **Hibernate/CGLIB Proxies:** Walks up the superclass chain via `Class#getSuperclass()`

**Example:**

  Class&lt;?&gt; proxyClass = userProxy.getClass();  // e.g., User$$EnhancerBySpringCGLIB$$abc123
  Class&lt;?&gt; real = unproxyType(proxyClass);      // returns User.class
```

**Parameters:**

- `aClass` - the class to unwrap; may be null

**Returns:**

the underlying real type, or the input class if it is not a proxy.
Returns `null` if input is `null`.

**See Also:** #isProxyType(Class)

## NScorable

```

Interface representing a "scorable" entity.



A scorable is any object whose instances can be assigned a score (or level of support)
within a given context. Scores are used by the framework to select the most appropriate
implementation or instance among several alternatives. Scorable objects are commonly used
for runtime selection of providers, callables, or actions.






Implementations of `NScorable` must define how the score is computed for a

The framework provides static utility methods to query and validate scorable instances.
Scorable objects are immutable with respect to score evaluation; the only input to
scoring is the [NScorableContext](#cls-NScorableContext).
