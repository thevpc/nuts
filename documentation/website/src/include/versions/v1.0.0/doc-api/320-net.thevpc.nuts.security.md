# Package net.thevpc.nuts.security

<a id="pkg-net-thevpc-nuts-security"></a>

Authentication, credentials, repository access, users, and secret handling.



It defines authentication agents and security management, user and credential
models, repository-access specifications, and scoped access to secure strings,
tokens, and secrets. Secret values are intentionally exposed through caller/runner
callbacks to limit their lifetime and visibility.

<a id="m-NNamedCredential-credential"></a>

#### credential

```java
NSecureToken credential()
```

Opaque credential identifier in `agent#version:payload` format.
This is the exact value that can be passed to
[NSecurityManager#addSecret(char[])](#cls-NSecurityManager) for decryption.



Example: `"default#1:HaT9KSjgfqdBFSgshPDh6UcFJ5T/ly2q0s7fUMGiRzHFPfhkYi5Ovr9DxsGj4ZbLwBm1w9UhCGYzz749lIFLtug=="`






**Security note:** This is encrypted ciphertext — not the raw secret.
It is safe to store in config files but MUST NOT be treated as the actual password/token.

**Returns:**

opaque credential identifier (agent#version:payload)
