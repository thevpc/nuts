# Package net.thevpc.nuts.expr

<a id="pkg-net-thevpc-nuts-expr"></a>

The `net.thevpc.nuts.expr` package provides a complete framework for
defining, parsing, compiling, and evaluating expressions within Nuts.



Expressions are abstract syntax trees (ASTs) composed of nodes, operators,
functions, variables, and literals, allowing runtime evaluation and template
processing.







Key features:


- **Expression nodes:** Represent the building blocks of expressions,
        including literals, variables, operators, function calls, conditional nodes,
        and interpolated strings.
- **Evaluation:** NExprEvaluator and related classes provide mechanisms
        for evaluating expression trees against variable bindings and runtime context.
- **Operator system:** Supports defining custom operators, their precedence,
        associativity, and evaluation rules.
- **Functions and templates:** Support for declaring functions,
        constructs, and template-based expressions that can be compiled and reused.
- **Extensibility:** Users can define new operators, functions, or AST node types,
        allowing integration with custom data types and domain-specific logic.
- **Error handling:** NExpressionException and related mechanisms provide
        detailed feedback when evaluation or parsing fails.









Typical use cases:


- Evaluating dynamic formulas and conditions at runtime.
- Implementing domain-specific languages or scripting within Nuts applications.
- Template evaluation and variable interpolation in configurations and outputs.
- Custom operators and functions for application-specific logic.









This package is tightly integrated with other Nuts frameworks, especially
the [net.thevpc.nuts.elem](#cls-net-thevpc-nuts-elem) package for representing structured data
and supporting expression evaluation on elements and their properties.

## NEvaluationException


Generic exception to be thrown when evaluation failed.

**Author:** thevpc

**Since:** 0.5.4

### Constructors

#### `NEvaluationException(NMsg message)`

```java
public NEvaluationException(NMsg message)
```

Constructs a new runtime exception with the specified detail message.
The cause is not initialized, and may subsequently be initialized by a
call to [#initCause](#m-initCause).

**Parameters:**

- `message` - the detail message. The detail message is saved for
               later retrieval by the [#message()](#m-message) method.


#### `NEvaluationException(NMsg message, Throwable cause)`

```java
public NEvaluationException(NMsg message, Throwable cause)
```

Constructs a new runtime exception with the specified detail message and
cause.


Note that the detail message associated with
`cause` is __not__ automatically incorporated in
this runtime exception's detail message.

**Parameters:**

- `message` - the detail message (which is saved for later retrieval
               by the [#message()](#m-message) method).
- `cause` - the cause (which is saved for later retrieval by the
               [#getCause()](#m-getCause) method).  (A `null` value is
               permitted, and indicates that the cause is nonexistent or
               unknown.)


#### `NEvaluationException(NMsg message, Throwable cause, boolean enableSuppression, boolean writableStackTrace)`

```java
public NEvaluationException(NMsg message, Throwable cause, boolean enableSuppression, boolean writableStackTrace)
```

Constructs a new runtime exception with the specified detail
message, cause, suppression enabled or disabled, and writable
stack trace enabled or disabled.

**Parameters:**

- `message` - the detail message.
- `cause` - the cause.  (A `null` value is permitted,
                          and indicates that the cause is nonexistent or unknown.)
- `enableSuppression` - whether or not suppression is enabled
                          or disabled
- `writableStackTrace` - whether or not the stack trace should
                          be writable
