# Package net.thevpc.nuts.internal.artifact

<a id="pkg-net-thevpc-nuts-internal-artifact"></a>

Internal implementations of artifact identity and version value objects.



This package backs public contracts in `net.thevpc.nuts.artifact`; use
their factories and builders instead of depending on these implementation classes.
