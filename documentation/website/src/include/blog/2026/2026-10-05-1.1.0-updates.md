## Changes


## Changes Details
- 2026-11-06 : added `NElements::fromElement(NElement, Type)` and `NElements::convert(Object, Type)` to deserialize generic targets such as `List<MyBean>` (use `new NTypeReference<List<MyBean>>(){}.type()`)
- 2026-11-06 : added `NReflectType::findSuperType(Class)` returning the resolved parametrized view of a super class/interface (e.g. `Map<String,Integer>` for `class Props extends HashMap<String,Integer>`)
- 2026-11-06 : fixed `NReflectType` generics : `superType()`/`interfaces()` of parametrized types, type variables substituted at any depth (nested arguments, arrays, wildcards, owner types), so inherited properties resolve correctly (`Leaf extends Mid<Integer>`, `Mid<X> extends Base<List<X>>`)
- 2026-11-06 : fixed `NReflectType::isAssignableFrom` (parametrized types and wildcards), `toArray` (primitives, nested classes, arrays), `rawType` (no more null for classes), JDK compatible names/equality of synthetic types, NPE in `getDeclaredProperty`/`declaredMethods`, thread safe type cache
- 2026-11-06 : fixed element deserialization of generic types : collection/map subclasses (`class PersonList extends ArrayList<Person>`), raw concrete maps (`TreeMap`), `Deque`/`HashSet`/`BlockingQueue` targets, `Map.Entry` value type, generic arrays (`List<X>[]`), wildcards (`List<? extends X>`), generic records and `Object` targets (no more `NOptional` values)
- 2026-11-06 : added `Iterable` mapping : non `Collection` iterables are serialized as arrays (`NToElement` still honored) and deserialized as collections or through a `List`/`Collection`/`Iterable` constructor
- 2026-11-06 : fixed `NTypeReference` equality (two references to the same type are now equal), JDK compatible parametrized type and `NTypeReference.of(List.class, String.class)` now builds `List<String>`
- 2026-11-05 : added support for record creation
- 2026-11-05 : added NMsgSnapshot
- 2026-10-27 : added NText::ntfText
- 2026-10-26 : fixed DefaultNUncompress issue
- 2026-10-23 : fixed Yaml parsing support
- 2026-10-23 : fixed MTF parsing support issues
- 2026-10-23 : fixed NTF parsing support issues
- 2026-10-20 : The re-exec path now preserves the child process’s exit code and restores the interrupt flag if waiting is interrupted.
- 2026-10-20 : fixed Boot issue when similarity explodes
- 2026-10-18 : added NSystemTerminalBase::interruptHandler
- 2026-10-15 : added better Complex number support
- 2026-10-05 : added cookies support : `NHttpRequest::cookies`
- 2026-09-26 : boot messages about maven demoted to debug (from warnings)
